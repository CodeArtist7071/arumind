## Linear/Circular Race

## Important terms used in race :

**Linear race** - it is a straight path such that the starting and finishing point don’t coincide with each other.

**Circular race** - it is a circular path such that the starting and finishing point coincide with each other.

**Dead Heat or Dead Lock -** A dead heat situation is when all participants reach the finishing point at the same time.

**Head-start -** when a racer gets a start ahead of the starting point .It is called head start.

## Circular race concepts

● Let A and B be two racers running in a circular path of length of L with speed S<sub>1</sub> and S<sub>2</sub> respectively. (S<sub>1</sub>>S<sub>2</sub>)

**Case 1 : when both racers running in the same direction /**

![](images/page_425_image_29.jpg)

Same direction

(I) Time taken to meet for the 1st time at the starting point = LCM of $( \frac { L } { S _ { _ 1 } } , \frac { L } { S _ { _ 2 } } )$

(II) Time taken to meet for the 1st time at anywhere on the track $= ( \frac { L } { S _ { 1 } ^ { \phantom { \dagger } } { } ^ { - S _ { 2 } ^ { \phantom { \dagger } } } } )$

**Case 2 : when both racers running in the opposite direction /**

![](images/page_425_image_34.jpg)

Opposite direction

(I) Time taken to meet for the 1st time at the starting point = LCM of $( \frac { L } { S _ { _ 1 } } , \frac { L } { S _ { _ 2 } } )$

(II) Time taken to meet for the 1st time at anywhere on the track $= ( \frac { L } { S _ { 1 } ^ { } + S _ { 2 } ^ { } } )$

## Number of meeting points :

• All the distant meeting points are equidistant in a circular path and the same goes for time.

• It is independent of the length of the track

• To get the no of different meeting points, find the simplest ratio of the two speeds i.e. x : y

**Case1 :** No. of meeting points when two runners running in same direction = x - y

**Case2 :** No. of meeting points when two runners running in opposite direction= x + y
