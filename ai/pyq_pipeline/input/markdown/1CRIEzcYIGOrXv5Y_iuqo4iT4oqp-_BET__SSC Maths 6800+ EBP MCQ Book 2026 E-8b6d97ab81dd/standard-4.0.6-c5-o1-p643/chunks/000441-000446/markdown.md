## Percentage

## Key Points :-

What does a percentage, say 20% mean? 20% simply means $\frac { 2 0 } { 1 0 0 }$ of something. Also, you can see $\frac{20}{100} = \frac{1}{5} = 0.2$

i.e. 0.2 of something is the same as 20% of that thing.

Percentage change $= { \frac { \; N e w \; v a l u e - O r i g i n a l \; v a l u e \; } { O r i g i n a l \; v a l u e } } \times$ 100

Percentage point change means difference between two percentage rates. For instance, $50\% - 30\% = 20\%,$ so here the percentage point change is 20.

If the price of a product increases by $a \% ,$ then to keep expenditure same, percentage reduction in consumption required $= ( \frac{a}{100 + a} \times 100 ) \%$

If the price of a product decreases $a \% ,$ then to keep expenditure same, percentage increase in consumption required $= ( \frac{a}{100 - a} \times 100 ) \%$

If A is R% more than B, then B is less than $A \mathrm{by} = \left( \frac{R}{100 + R} \times 100 \right) \%$

If A is R% less than B, then B is more than $A \mathrm{by} = \left( \frac{R}{100 - R} \times 100 \right) \%$

If the number is first increased by x% and then decreased by x%, then the net result is always decrease and it is equal to $t = ( \frac{x^{2}}{100} ) \%.$ Same result will be obtained in the vice-versa case.

<strong><u>Successive percentage change :</u></strong>

1. Two successive percentage change : If the number is first increased by a% and then increased by b% then, Effective percentage change $(a+b+\frac{ab}{100})\%$ Similarly, if the number is first increased by a% and then decreased by b%, then Effective percentage change $= ( a - b - \frac { a b } { 1 0 0 } ) \%$

2. Three successive percentage change : If the number is first increased by a% then by b% and

then by c%, then

Effective percentage change =

$$
(a + b + c + \frac {a b + b c + c a}{1 0 0} + \frac {a b c}{1 0 0 0 0})\%
$$
