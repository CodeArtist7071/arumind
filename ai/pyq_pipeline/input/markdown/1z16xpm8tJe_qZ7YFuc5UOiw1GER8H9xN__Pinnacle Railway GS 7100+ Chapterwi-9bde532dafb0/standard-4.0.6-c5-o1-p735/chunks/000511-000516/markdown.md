**Q.765.** The work done by non-conservative forces in a closed loop is

RRB Tech. - (I) 19/12/2024 (Afternoon)

(a) always zero

(b) dependent on the path

(c) independent of the path

(d) negative

**Sol.765.**(**b) dependent on the path.**

Non-conservative forces (like friction, air resistance, etc.) are path-dependent, meaning the work done depends on the actual trajectory taken, not just the start and end points.
