**Sol.391.(d) establishing uniform police and judiciary reforms.** The Cornwallis Code of 1793, implemented by Lord Cornwallis, is a landmark in British Indian administration. It is primarily remembered for bringing about uniform reforms in the police, judiciary, and civil administration.
