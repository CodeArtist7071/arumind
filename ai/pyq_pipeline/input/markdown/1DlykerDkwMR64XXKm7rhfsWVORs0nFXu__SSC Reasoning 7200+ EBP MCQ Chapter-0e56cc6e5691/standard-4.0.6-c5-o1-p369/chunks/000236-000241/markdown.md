## Counting of Figure

**Basic of counting figure -**

In this chapter, several shapes are given inside a shape (e.g. triangle, rectangle, square, straight line) in which we have to find the number of shapes. Let us understand this by following some questions.

**Type - 1 :-**

Some tricks to find number of triangles:- **(i)**

![](images/page_237_image_8.jpg)

Number of triangle → 1

**(ii)**

![](images/page_237_image_11.jpg)

Number of triangles → 1 + 2 = 3

**(iii)**

![](images/page_237_image_14.jpg)

Number of triangles → 1 + 2 + 3 = 6

**(iv)**

![](images/page_237_image_17.jpg)

Number of triangles → 1 + 2 + 3 + 4 = 10

**(v)**

![](images/page_237_image_20.jpg)

Numbers of triangles →

{(Sum of triangle part) × Highest height } → (1 + 2 + 3 + 4) × 3 = 30

**(vi)**

![](images/page_237_image_24.jpg)

Numbers of triangles → 2 × no. of parts $2 \times 8 = 16$

**Note :- Special cases of triangles**

![](images/page_237_image_27.jpg)

![](images/page_237_image_28.jpg)

8-triangles

10-triangles

**Type - 2 :-**

Some tricks to find number of square:-

**(i)** when row and column are equal →

| 1 | 2 | 3 |
| --- | --- | --- |
| 2 |  |  |
| 3 |  |  |

**Solution : -**

No. of rows and columns are 3 . So, number of squares $= 1 ^ { 2 } + 2 ^ { 2 } + 3 ^ { 2 }$ = 14

**(ii)** when row and column are not equal →

| 1 | 2 | 3 | 4 |
| --- | --- | --- | --- |
| 2 |  |  |  |
| 3 |  |  |  |

**Solution: -**

![](images/page_237_image_40.jpg)

Total Number of squares →

$$
(4 \times 3) + (3 \times 2) + (2 \times 1) = 1 2 + 6 + 2 = 2 0
$$

**Type - 3 :-**

Some tricks to find number of rectangles:-

**(i)** when row and column are equal →

| 1 | 2 | 3 |
| --- | --- | --- |
| 2 |  |  |
| 3 |  |  |

**Solution : -**

Total number of Rectangle → (1 + 2 + 3) × (1 + 2 + 3) = 36

**(ii)** when row and column are not equal =

| 1 | 2 | 3 | 4 |
| --- | --- | --- | --- |
| 2 |  |  |  |
| 3 |  |  |  |

**Solution: -**

Total number of Rectangle → (1 + 2 + 3 + 4) × (1 + 2 + 3) = 60
