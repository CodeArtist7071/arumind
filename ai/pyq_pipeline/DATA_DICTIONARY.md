# Workbook data dictionary

The `Questions` sheet has one row per stable `record_id`. `source_document` displays the source document's parent folder name (with an extraction ID prefix removed when present); `source_file` retains the full path for precise traceability. `exam`, `subject`, `chapter`, and `topic` are canonical names when mapped and otherwise the source labels. Their corresponding `*_id` columns contain only IDs loaded from the active registry. `options_json` preserves all option labels and order; `option_a` through `option_d` are convenience columns. `correct_answers` contains source-printed or context-matched answer values and must be interpreted with `answer_verification_status`. `source_hash`, `source_page`, offsets, and question number also locate the source. `mapping_status`, `extraction_status`, and answer status are review states, not assertions of truth. `review_reasons` preserves actionable concerns. Long cells are referenced in `long_cells.jsonl`.

`Review Queue` contains records with validation issues, unresolved metadata, conflicts, or other review reasons. `Mapping Audit` records each raw taxonomy value and its exact mapping method/candidates. `Duplicate Candidates` reports same-source or same-exam/year exact-text candidates and never removes records. `Processing Summary` reports state and quality counts.
