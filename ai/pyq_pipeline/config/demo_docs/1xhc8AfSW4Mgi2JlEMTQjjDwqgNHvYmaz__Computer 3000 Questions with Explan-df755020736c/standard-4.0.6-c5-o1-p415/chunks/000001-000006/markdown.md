## Q.5 What does POST stand for in the context of computers?

(1) Power-On Self-Test (2) Power-On System Test

(3) Post-Operating System Test (4) Pre-Operating System Test

(5) None of the above

UPSSSC X-Ray Technician 15.12.2024

## Solution: Correct Answer is Power-On Self-Test Explanation:

POST stands for Power-On Self-Test. It is a crucial part of the computer's start-up process managed by the BIOS (Basic Input/Output System). When you turn on the computer, POST automatically performs a basic check of hardware components such as RAM, CPU, hard disk, keyboard, and other devices. It ensures that all hardware is functioning properly and there are no critical errors before the operating system loads. If POST is successful, the computer continues with the boot process; otherwise, it indicates the problem through beep codes or error messages.

Q.9 When one device attempts to send a message to another device, the data is sent over the internet in the form of manageable packets and each packet is assigned a .... that will connect it to its endpoint.

(1) network number (2) computer number

(3) port number (4) router number UPPCL Executive Assistant 24-11-2022 Shift-II

## Solution: Correct Answer is port number

## Explanation:

Internet data transmission is based on packet switching technology. When one device sends a message to another device, data is divided into small packets. Each packet is assigned a specific port number to reach its destination. A port number is a 16-bit numerical identifier that represents a specific application or service. It operates at the Transport Layer of the TCP/IP model and ensures data reaches the correct application. For example, HTTP uses port 80 and HTTPS uses port 443.

Q.15 A storage device used to compensate the difference in flow of data is known as

(1) main memory (2) auxiliary memory

(3) buffer (4) More than one of the above

(5) None of the above

BPSC TRE 2.0 Exam-2023 (11-12)

## Solution: Correct Answer is buffer

## Explanation:

A buffer is a temporary storage area used to compensate for differences in data flow rates between two devices or processes. It is typically located in the main memory (RAM) and helps manage speed mismatches during data transfer. For instance, when a CPU sends data to a printer, the buffer temporarily stores the data to handle the speed disparity. This ensures data integrity and improves system efficiency. While main memory and auxiliary memory are used for permanent storage, a buffer is specifically designed for data flow management.
